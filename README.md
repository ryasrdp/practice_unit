# practice_unit

Small JavaScript utility library with unit tests using Mocha + Chai.

## Prerequisites

- Node.js 18+ (Node.js 20 recommended)
- npm 9+

## Installation

```bash
npm install
```

## Available Scripts

### Run all tests

```bash
npm test
```

This runs Mocha with Babel register:

```bash
mocha --require @babel/register
```

### Run tests with coverage

```bash
npm run coverage
```

### Run lint checks

```bash
npm run lint
```

## Quick Start

```bash
npm install
npm test
```
